## Editor de texto con imágenes

Una aplicación que permite escribir texto usando un conjunto de imágenes como fuente para cada letra. Desarrollado como colaboración artística con [@duerme_volantina](https://www.instagram.com/duerme_volantina/).

## Configuración

1. Instalar uv
2. Sincronizar dependencias
```bash
uv sync
```
3. Ejecutar
```
uv run src/main.py
```
